# Jellyfin Avatar Packs

This repository contains several ready-to-use avatar packs for the **[Jellyfin-GetAvatar](https://github.com/cedev-1/jellyfin-plugin-GetAvatar)** plugin or other.

## Content

Each folder corresponds to an avatar pack:

- `dp` — Disney Plus
- `nf` — Netflix
- `one` — Xbox One
- `playstation` — Playstation
- `pp` — Paramonth Plus
- `pv` — Prime Video
- `Steam` — Steam

## Usage

### 1. Clone the repository

```bash
git clone https://github.com/cedev-1/jellyfin-avatars.git
```

### 2. Import into Jellyfin-GetAvatar

1. Open the Jellyfin administration interface.
2. Go to **Dashboard** → **Plugins** → **GetAvatar** → **Settings**.
3. click **Add folder**.
4. Select the folder of the pack you want to add (e.g. `nf/`, `Steam/`, etc.).
5. The **Category** field is automatically filled with the folder name. You can override it by entering a custom name before clicking **Import**.
6. Repeat the operation for each desired pack.
7. The avatars are then available for users.
